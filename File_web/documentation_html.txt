<Html> : es para que se inicie el programa
<head> : dentro se encuentra todo el backend (style, link, meta, etc)
<body> : dentro se encuentra todo el frontend (img, p, div, etc)

<---------------------Dentro de Head--------------------->
<meta charset= utf-8> : es un formato de codificación de caracteres que permite que los ordenadores puedan mostrar textos en distintos idiomas (ponerlo y ya son simbolos)
<link> : sirve para utilizar o activar otro archivo, pagina web, etc (el enlace se pone en href)
<style> : sirve para escribir codigo css en html (no se recomienda para un codigo largo solo para cosas puntuales y ni eso)
<script> : igual que style solo que para javascript (este si se recomienda ya que no suele haber mucho codigo js pero si hay mucho mejor hacer un link)
<title> : sirve para dar nombre a la pagina web (si no tienes un dominio web)

<---------------------Dentro de body--------------------->

<-___________-Sin significado semantico-_________________>
<div> : sirve para agrupar en bloques los elementos html
<p> : sirve para mostrar texto en la pantalla
<span> sirve para editar alguna palabra o frase dentro de una funcion ej: <p> Hola <span style="color= blue"> como </span> estas </p>
<h1,2,3,4,5,6,7,8,9> : es como un p lo que pasa es que es mas ordenado, ej: h1 es el titulo, etc
<table> : es como un html lo unico que para que se puedan poner los elementos :
thead, tbody, tr y td (es para agrupar la informacion con un orden, como una tabla de excel)
    <thead> : es el backend pero se escribe texto que luego se ve, es mejor verlo con un ejemplo:
        <thead>
            <tr>
                <th colspan="4">Ejemplos</th> (Aqui lo que ponemos es un th que sirve para poner el titulo y para poner la variable colapsan que lo que hace es decir en cuantas
                                                pueden ir seguidas en la misma linea, si pones 5 <td> y en el colapsan pones cuatro la 5 se pone debajo de la primera)
            </tr>
        </thead>
    <tbody> : es el frontend, ejemplo
    <tbody>
        <tr>
            <td>Musica</td> (<td> sirve para escribir un dato en una columna)
            <td>Produccion</td>
            <td>web</td>
            <td>diseños</td>
                        
        </tr>

    </tbody>
    <tr> : sirve para crear una fila, un cuadrado ordenado como si fuera una tabla como un div y luego con el th y el td le das forma
    <ul> : sirve para crear un lista desordenada
    <ol> : sirve para crear un lista ordenada
    <li> : sirva para escribir datos dentro de un ul o ol
    <a> : es un boton donde tu pulsas y te lleva a algun enlace(tiene href)
    

<-___________-Con significado semantico-_________________>

<nav> : es un div que sirve para decir al lector de pantalla donde esta el menú de la página web
<section> : es un div que sirve para agrupar toda la informacion de un tema en general (luego eso se puede dividir en <article>)
<article> : es un div que sirve para dividir conceptos (o contenidos) que pertenecen a un tema general.
<header>: Encabezado de la página o sección, suele incluir logo, título y navegación.
<main>: Contenido principal único de la página, lo más importante para el usuario.
<footer>: Pie de página o sección, con información de copyright y enlaces a políticas o datos de contacto.

ESQUEMA DE FORMULARIO HTML
=========================

FORMULARIO (<form>)
│
├─ Atributos:
│   ├─ action="URL"  → Define a dónde se envían los datos
│   └─ method="GET/POST" → Define cómo se envían los datos
│
├─ ELEMENTOS INTERNOS
│   │
│   ├─ <label>
│   │   ├─ for="id_del_input" → Vincula el label con un input específico
│   │   └─ Texto descriptivo
│   │
│   ├─ <input>
│   │   ├─ type="tipo" → Define el tipo de dato (text, email, password, number, submit...)
│   │   ├─ id="id_del_input" → Identificador único, este tiene que ser igual al for
│   │   └─ name="nombre_del_campo" → Nombre usado al enviar datos al servidor
│   │
│   └─ <button>
│       └─ type="submit" → Envía los datos del formulario
│
├─ EJEMPLO COMPLETO
│
│ <form action="/procesar-datos" method="post">
│   <label for="usuario">Nombre:</label>
│   <input type="text" id="usuario" name="usuario">
│
│   <label for="correo">Correo:</label>
│   <input type="email" id="correo" name="correo">
│
│   <button type="submit">Enviar</button>
│ </form>
│

ESQUEMA DE <select> Y <option>
===============================

<select>
│
├─ Atributos importantes:
│   ├─ id="pais" → identificador único (para <label> o JS)
│   └─ name="pais" → nombre del campo enviado al servidor
│
├─ Contiene varias etiquetas <option>
│   ├─ Texto visible → lo que ve el usuario
│   └─ value → valor real que se envía al servidor
│
├─ Ejemplo:
│
│ <select id="pais" name="pais">
│   <option value="es">España</option>
│   <option value="mx">México</option>
│   <option value="ar">Argentina</option>
│ </select>
│
└─ Funcionamiento:
    - Si elige España → pais=es
    - Si elige México → pais=mx
    - Si elige Argentina → pais=ar
