🔹 let

Variable que puede cambiar su valor.

Solo se puede usar dentro del bloque donde se declara (por ejemplo, dentro de un if o función).

🔹var

lo mismo que let pero funciona en toda la funcion, osea si tu creas un let dentro de un if y luego lo necesitas fuera del if, tienes dos

opciones: crear el let fuera del if y darle el valor dentro del if o en vez de let usas var

🔹 const

Variable constante, no se puede cambiar una vez asignada.

También solo existe dentro del bloque donde se declara.

es parecido a un private en java

🔹 Ejemplo sencillo (para entenderlo rápido)

let edad = 20 → luego puedes cambiar a 21.

const pi = 3.14 → no puedes cambiar a otro valor. (bueno si puedes, si haces algo parecido a un getter y un setter en java puedes hacerlo)

Resumen completo: Cómo usar addEventListener() en JavaScript

===========================================================

¿Qué es addEventListener?
-------------------------
Es un método que permite asociar una función (manejador de eventos) a un elemento HTML para que se ejecute cuando ocurra un evento específico.

Ventajas sobre onclick y atributos HTML:
- Permite múltiples escuchadores para el mismo evento.
- Mejor control del flujo de eventos (captura y burbuja).
- Código más limpio y mantenible.

Sintaxis Básica:
----------------
elemento.addEventListener(tipoDeEvento, funcionManejadora, [opciones]);

Parámetros:
-----------
1. tipoDeEvento (String): El nombre del evento a escuchar.
   Ejemplos: 'click', 'mouseover', 'keydown', 'submit'

2. funcionManejadora (Function): La función que se ejecuta cuando ocurre el evento.
   Puede ser una función anónima o una función nombrada.

3. opciones (Object - Opcional): Un objeto con configuración.
   - capture: Boolean (fase del evento)
   - once: Boolean (si se ejecuta solo una vez)
   - passive: Boolean (para eventos de scroll/touch, mejora rendimiento)

Uso de "useCapture" (alternativa legada):
elemento.addEventListener(evento, funcion, useCapture);
- useCapture = true: Fase de captura
- useCapture = false (default): Fase de burbuja

Métodos Comunes para Obtener Elementos:
---------------------------------------
- document.getElementById('id')
- document.querySelector('.clase')
- document.querySelectorAll('div')[0]

Eventos Comunes:
----------------
- Mouse: click, dblclick, mouseenter, mouseleave, mousemove
- Teclado: keydown, keyup, keypress
- Formularios: submit, change, focus, blur
- Ventana: load, resize, scroll

Ejemplos Prácticos:
-------------------

1. Evento de Click básico:
const boton = document.getElementById('miBoton');
boton.addEventListener('click', function() {
    alert('Botón clickeado!');
});

2. Con función externa:
function manejarClick() {
    console.log('Click manejado');
}
boton.addEventListener('click', manejarClick);

3. Con parámetros (usando función anónima):
boton.addEventListener('click', function() {
    miFuncionConParametros(param1, param2);
});

4. Evento con objeto Event:
boton.addEventListener('click', function(evento) {
    console.log(evento.target); // Elemento que disparó el evento
    evento.preventDefault(); // Prevenir comportamiento por defecto
});

5. Opción once (se ejecuta una sola vez):
boton.addEventListener('click', function() {
    console.log('Solo se ejecuta una vez');
}, { once: true });

6. Múltiples eventos en un elemento:
boton.addEventListener('mouseover', function() {
    this.style.backgroundColor = 'blue';
});
boton.addEventListener('mouseout', function() {
    this.style.backgroundColor = '';
});

Remover Event Listeners:
------------------------
Para remover un event listener, debe usarse una función nombrada:
const miFuncion = function() { ... };
elemento.addEventListener('click', miFuncion);
elemento.removeEventListener('click', miFuncion);

Consideraciones de "this":
---------------------------
En un event listener, "this" hace referencia al elemento que disparó el evento, a menos que se use una arrow function.

Buenas Prácticas:
-----------------
1. Usar funciones nombradas cuando necesites remover el listener.
2. Preferir addEventListener sobre onclick en el HTML.
3. Considerar event delegation para elementos dinámicos.
4. Remover listeners cuando ya no sean necesarios para evitar memory leaks.

Event Delegation:
-----------------
En lugar de agregar listeners a muchos elementos, agregar uno al padre:
document.getElementById('lista').addEventListener('click', function(e) {
    if (e.target.tagName === 'LI') {
        console.log('Elemento de lista clickeado:', e.target);
    }
});

Soporte Navegadores:
--------------------
addEventListener es compatible con todos los navegadores modernos e IE9+.

RESUMEN COMPLETO DE DOCUMENT EN JAVASCRIPT
==========================================

¿QUÉ ES EL DOCUMENT OBJECT MODEL (DOM)?
----------------------------------------
El Document en JavaScript es una representación estructurada en forma de árbol 
de un documento HTML. Es la interfaz principal para trabajar con el contenido 
de una página web.

ACCESO AL OBJETO DOCUMENT
-------------------------
// En navegadores, document está disponible globalmente
console.log(document);

// También se puede acceder a través de window
console.log(window.document);

MÉTODOS PRINCIPALES PARA SELECCIONAR ELEMENTOS
----------------------------------------------

1. Selección por ID
const elemento = document.getElementById('miId');

2. Selección por clase
const elementos = document.getElementsByClassName('miClase');
// Retorna una HTMLCollection

3. Selección por etiqueta
const elementos = document.getElementsByTagName('div');
// Retorna una HTMLCollection

4. Selección por selector CSS (moderno)
// Selecciona el primer elemento que coincida
const elemento = document.querySelector('.miClase');

// Selecciona todos los elementos que coincidan
const elementos = document.querySelectorAll('div.miClase');
// Retorna una NodeList

CREACIÓN DE ELEMENTOS
---------------------
// Crear nuevo elemento
const nuevoDiv = document.createElement('div');

// Crear nodo de texto
const texto = document.createTextNode('Hola Mundo');

// Añadir texto al elemento
nuevoDiv.textContent = 'Texto del div';
nuevoDiv.innerHTML = '<strong>Texto</strong> con HTML';

MODIFICACIÓN DEL DOM
--------------------
// Modificar valores
 const NumeroRandom = 1;
 console.log(NumeroRandom) // imprime 1
 NumeroRandom.value=2
 console.log(NumeroRandom) // imprime 2
Añadir elementos:
// Añadir al final
document.body.appendChild(nuevoDiv);

// Añadir en posición específica
const padre = document.getElementById('padre');
const referencia = document.getElementById('referencia');
padre.insertBefore(nuevoDiv, referencia);

// Métodos modernos
padre.append(nuevoDiv); // Al final
padre.prepend(nuevoDiv); // Al inicio

Eliminar elementos:
const elemento = document.getElementById('eliminar');
elemento.remove();

// Método antiguo
elemento.parentNode.removeChild(elemento);

Reemplazar elementos:
const viejoElemento = document.getElementById('viejo');
const nuevoElemento = document.createElement('div');
viejoElemento.parentNode.replaceChild(nuevoElemento, viejoElemento);

MANIPULACIÓN DE ATRIBUTOS Y CLASES
----------------------------------

Atributos:
const elemento = document.getElementById('miElemento');

// Obtener atributo
const valor = elemento.getAttribute('data-info');

// Establecer atributo
elemento.setAttribute('data-info', 'nuevo valor');

// Verificar atributo
if (elemento.hasAttribute('data-info')) {
    // Eliminar atributo
    elemento.removeAttribute('data-info');
}

Clases:
const elemento = document.getElementById('miElemento');

// Añadir clase
elemento.classList.add('nueva-clase');

// Eliminar clase
elemento.classList.remove('clase-vieja');

// Alternar clase
elemento.classList.toggle('activa');

// Verificar clase
if (elemento.classList.contains('activa')) {
    // Hacer algo
}

EVENTOS
-------

Añadir event listeners:
const boton = document.getElementById('miBoton');

// Método recomendado
boton.addEventListener('click', function(event) {
    console.log('Botón clickeado', event);
});

// Método antiguo (no recomendado)
boton.onclick = function() {
    console.log('Click antiguo');
};

Remover event listeners:
function manejarClick() {
    console.log('Click');
}

boton.addEventListener('click', manejarClick);
// Para remover luego
boton.removeEventListener('click', manejarClick);

PROPIEDADES IMPORTANTES DEL DOCUMENT
------------------------------------
- document.head: Accede al elemento <head>
- document.body: Accede al elemento <body>
- document.title: Obtiene o establece el título del documento
- document.URL: Retorna la URL completa del documento
- document.forms: Colección de todos los formularios
- document.images: Colección de todas las imágenes
- document.links: Colección de todos los enlaces

MÉTODOS ADICIONALES ÚTILES
--------------------------
// Crear un fragmento de documento (mejor performance)
const fragmento = document.createDocumentFragment();

// Clonar un elemento
const elementoOriginal = document.getElementById('original');
const clon = elementoOriginal.cloneNode(true);

// Verificar si un elemento contiene a otro
const contenedor = document.getElementById('contenedor');
const hijo = document.getElementById('hijo');
const contiene = contenedor.contains(hijo);

BUENAS PRÁCTICAS
----------------
1. Usar querySelector y querySelectorAll para selecciones complejas
2. Utilizar classList en lugar de className para manipular clases
3. Preferir addEventListener sobre onclick y similares
4. Usar createDocumentFragment para múltiples inserciones
5. Validar que los elementos existen antes de manipularlos

NOTAS IMPORTANTES
-----------------
- HTMLCollection y NodeList son colecciones similares a arrays pero no arrays
- Los métodos getElementsBy* retornan colecciones vivas
- querySelectorAll retorna una NodeList estática
- Siempre verificar null/undefined al seleccionar elementos
